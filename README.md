# ♻️ TrashHub — Smart Waste Management Platform

**TrashHub** is a web-based platform designed to streamline waste collection operations through digital scheduling, real-time tracking, and cashless payments.  
Built for urban and peri-urban communities in Kenya, it connects **Residents**, **Collectors**, and **Administrators** in one eco-friendly ecosystem.

---

## 🌍 Vision

To promote cleaner cities by empowering households and collection agencies with data-driven waste management tools.

---

## 🧩 System Overview

TrashHub operates through **three integrated user flows**:

### 1️⃣ Resident Flow (Web App)

**Goal:** Request pickups, track collection, and make payments with ease.

**Features:**
- **Sign Up / Login** — Residents register with full name, email, phone, location, and account type.
- **Dashboard** — Access main options:
  - 🗑️ *Request Pickup* — Select waste type (regular, bulk, e-waste, recyclables) and choose a pickup date/time.
  - 🕒 *View Schedule* — See upcoming and past pickups.
  - 💳 *Make Payment* — Integrated payment via **IntaSend** (MPesa, card, or subscription).
- **Tracking** — Real-time updates when collector is en route (Google Maps API integration).
- **Feedback** — Option to rate and review collection service after completion.

---

### 2️⃣ Collector Flow (Mobile / Web Hybrid)

**Goal:** Help collectors efficiently manage pickups, track routes, and report collection.

**Features:**
- **Login** — Collector access assigned by admin.
- **Pickup Requests** — View daily scheduled pickups.
- **Route Optimization** — Smart route suggestions via map integration.
- **Collection Actions:**
  - ✅ Mark pickups as “Collected.”
  - 📸 Upload photo proof for accountability.
- **Daily Reports** — Summary of completed vs. missed pickups.

---

### 3️⃣ Admin Flow (Web Dashboard)

**Goal:** Manage users, operations, and analytics for continuous improvement.

**Features:**
- **Login / Role-Based Access** — Only admins can view this dashboard (secured via Supabase Auth).
- **Overview Dashboard:**
  - Scheduled Pickups
  - Completed Pickups
  - Revenue Generated
- **User Management:**
  - Add or remove Residents and Collectors.
  - Assign collectors to routes.
- **Payment Tracking:**
  - Monitor payments (via IntaSend API).
  - Manage subscription plans.
- **Reports & Analytics:**
  - Charts showing waste collection by type (organic, plastic, e-waste).
  - Heatmap of waste-heavy zones.
  - Missed pickup statistics.

⚙️ Setup Instructions
1. Clone Repository
bash
Copy code
git clone https://github.com/yourusername/trashhub.git
cd trashhub

2. Create Supabase Project
Go to Supabase.

Create a new project.

Copy your SUPABASE_URL and SUPABASE_ANON_KEY into app.js.

3. Run SQL Schema
Use this SQL in Supabase Table Editor → SQL Editor:

sql
Copy code
create table profiles (
  id uuid references auth.users on delete cascade not null primary key,
  full_name text,
  email text unique,
  phone text,
  location text,
  account_type text check (account_type in ('Admin','Collector','Resident')),
  created_at timestamp default now()
);

create table pickups (
  id bigint generated by default as identity primary key,
  user_id uuid references profiles(id) on delete cascade,
  waste_type text,
  pickup_date timestamp,
  status text default 'Scheduled',
  proof_image text,
  created_at timestamp default now()
);

create table payments (
  id bigint generated by default as identity primary key,
  user_id uuid references profiles(id),
  amount numeric,
  status text default 'Pending',
  created_at timestamp default now()
);
4. Configure Email Verification
In Supabase → Authentication → Providers → Email

Enable Email Signups & Confirmations.

Redirect URL: http://localhost:5500/verify.html.

5. Setup IntaSend
Create an IntaSend account.

Obtain Public Key and integrate it in app.js under payment section.
